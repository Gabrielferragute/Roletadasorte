# 🎡 Sorteios com a Roleta

Sorteador online moderno, animado e auditável com roleta interativa.

## Recursos
- 🎲 **Roleta Interativa**: Giro suave com aceleração e desaceleração física realista.
- 🔊 **Efeitos Sonoros & Confetes**: Áudio procedural via Web Audio API e celebração em tela cheia.
- 🛡️ **Aleatoriedade Criptográfica**: Sorteio utilizando Web Crypto API (`window.crypto.getRandomValues`).
- 👥 **Fila de Participantes**: Alternância de participantes e avanço automático.
- 📊 **Quadro de Resultados**: Acompanhamento dos itens sorteados e exportação formatada para WhatsApp.

## Como Usar
Basta abrir o arquivo `index.html` em qualquer navegador ou hospedar em serviços estáticos como Vercel, Netlify ou GitHub Pages.
